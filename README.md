# 网页文本数据清洗智能系统与应用：从算法到系统实现

南京理工大学 学科导航课（2026）课程项目。报告见 `报告.pdf`。

## 目录
- `数据清洗管线.py` 爬取+规则清洗+配对+切分+校验，可复现数据集
- `正则表达式.py` 模型输出修复链（截断补全/schema 归一/幻觉过滤）
- `清洗器服务.py` 本地 LoRA 4bit 推理服务（127.0.0.1:8000）
- `清洗器微调.py` / `清洗器重训建议.py` / `微调练习.py` 训练脚本
- `data_cleaner/` 训练/测试配对数据（265 条）
- `eval_v1.json` / `eval_v2b.json` 两版模型对照评测原始结果
- `figures/` 报告插图
- `report_src/` 报告排版源文件

## 运行
conda 环境 myft（Python 3.12, PyTorch 2.10+cu126, Unsloth）。
模型权重（Qwen3-0.6B 底模与 LoRA 适配器）体积较大未入库，按报告第 6 节自行下载/训练。
